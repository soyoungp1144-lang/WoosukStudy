# 🧠 Python 자료구조 시각화 학습 도구

Python(Tkinter)로 구현한 **자료구조 학습용 GUI 도구**입니다.  
10개의 정수 데이터를 한 번에 입력한 뒤, 각 자료구조 탭에서 **애니메이션처럼 삽입 과정을 단계별로 확인**할 수 있습니다.

> 우석대학교 정보보안학과 박소영


---

## 📌 프로젝트 소개

자료구조 수업에서 C 언어 코드가 길고 복잡하게 느껴질 때,  
**Python으로 동작을 가볍게 시각화**해서 직관적으로 이해할 수 있도록 만든 도구입니다.

- 한 번에 입력한 정수 리스트(10개)를 이용해
- 스택, 큐, 힙, 트리 등 자료구조에 **하나씩 순차 삽입**
- 각 단계마다 **현재 구조 상태가 텍스트로 갱신**되어 흐름을 눈으로 따라갈 수 있습니다.

---

## 🔢 포함된 자료구조 (총 10개)

각 자료구조는 별도의 탭(Tab)으로 구성되어 있습니다.

1. Array (배열 / 리스트)
2. Stack (스택, LIFO)
3. Queue (큐, FIFO)
4. Deque (데크, 양쪽 입출력)
5. Singly Linked List (단일 연결 리스트)
6. Binary Search Tree (이진 탐색 트리, BST)
7. Min Heap (최소 힙)
8. Hash Table (해시 테이블, 체이닝 방식)
9. Set (집합, 중복 없음)
10. Graph (그래프, 인접 리스트 / `A-B` 형식 간선)
